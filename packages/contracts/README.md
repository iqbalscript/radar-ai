# API contracts

Shared request and response schemas for RADAR AI (`v1.0.0`).

- TypeScript definitions: `packages/contracts/src/radar-api.ts` (consumed by `apps/web` via `@radar-ai/contracts`).
- Python validation models: `apps/api/src/radar_api/contracts.py` (RDA-18).

Keep contracts versioned and link schema changes to the relevant Jira issue (`RDA-4`, `RDA-18`) and pull request. Research prototype only; not for clinical use.
